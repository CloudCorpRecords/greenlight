How to read the classes

A repo can carry several classes. Evidence under each card tells you exactly what proves the class: the policy file, the workflow, or what happened to our PR. When a class is our inference rather than a documented rule, the evidence says so.

Method

Entries begin with the October 2026 contribution campaign: real issues claimed, real pull requests opened, real bots and policies met face to face. Since then the dataset keeps growing through read-only scans run with Greenlight, the same tool that powers the Contribution Friction Index. Every entry carries the date it was last verified, and this page recomputes every count from the data itself, so the numbers you see are never older than the dataset. Policy can change, so always read a repo's own policy files before you build for it.

The raw dataset is published for machines at policy.json (CC-BY-4.0). Greenlight's own gates implement this taxonomy: run npx @reneturcios/greenlight check <issue-url> and the repo's agent policy is checked before you invest a weekend.
